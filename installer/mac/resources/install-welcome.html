Font Manager for PowerPoint

This adds Font Manager to PowerPoint for Mac, for your user account. It checks which fonts the open deck actually uses, which of those are installed on this Mac, and fetches the missing ones as downloads, metric-compatible substitutes or a bundle for another machine.

Nothing is copied into Applications. The installer puts one small file in PowerPoint’s add-ins folder, which points PowerPoint at pptx-font-manager-addin.stoatworks-labs.com. The add-in runs from there, so it keeps itself up to date.

PowerPoint has to be closed while it installs. If it’s open, the installer will ask to quit it.
